# NHL Fantasy Hockey Predictor #
NHL Fantasy Hockey Prediction Model in Python
* Cameron Fietz

## REQUIREMENTS
- Python
- numpy
- scikit-learn
- textual

To install all dependencies:\
`pip install -r requirements.txt`

## USAGE
- Run `ui.py`

| Mode | Description |
| :--- | :--- |
| `PREDICT SEASON` | Run a fantasy hockey prediction for a specific season |
| `PREDICT PLAYER` | Run a fantasy hockey prediction for a specific player ID |
| `PLAYER SEARCH` | Search for player ID using first or last name |
| `EDIT POINT VALUES` | Customize point value modifiers for each stat |
